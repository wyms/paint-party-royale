# Paint Party Royale

A kid-friendly, Fortnite-style battle royale that runs in the browser: glide in, harvest materials, build walls, ramps, and floors, and blast 19 bots with paint blasters until you're the last one standing. There's no real violence: tagged players get beamed back to the lobby in a burst of confetti.

**Play:** open `index.html` in a browser (or visit the GitHub Pages site). You'll need a keyboard and mouse.

| Key | Action |
| --- | --- |
| WASD / Mouse | Move / look and aim |
| Click / Right-click | Blast (or place a build piece) / zoom aim |
| Space / Shift | Jump / sprint |
| Q / E / C | Wall / ramp / floor build mode (press again, or 1, to go back to the blaster) |
| F | Harvest trees and rocks for mats |
| R / B / Esc | Reload / dance / pause |

The game is a single static file with no build step. It uses three.js from the jsDelivr CDN.
