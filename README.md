# Paint Party Royale

A kid-friendly 5v5 paintball game that runs in the browser. You're on the Blue team with 4 bot teammates, playing against 5 Orange bots on a netted field full of inflatable bunkers.

**How to win a round:** paint out everyone on the other team, or grab the flag in the middle and hang it at their base. Each player is out after 3 hits (4 on Normal, 5 on Chill). Painted-out players raise their marker and walk off the field. The first team to win 2 rounds wins the match.

**Play:** open `index.html` in a browser (or visit the GitHub Pages site). You'll need a keyboard and mouse.

| Key | Action |
| --- | --- |
| WASD / Mouse | Move / look and aim |
| Click / Right-click | Shoot (or place a build piece) / zoom aim |
| X (hold) | Crouch behind low bunkers |
| Space / Shift | Jump / sprint |
| Q / E / C | Wall / ramp / floor (limited mats each round; press again or 1 to go back to your marker) |
| R / B / Esc | Reload / dance / pause |

Choose from 3 markers: **Classic** (balanced), **Speedball** (fast and sprayier), or **Pump Sniper** (slow, pinpoint, long range).

The game is a single static file with no build step. It uses three.js from the jsDelivr CDN.
